# Inherited plugin icon

The bundled `.claude-plugin/icon.png` and `icon.svg` are existing artwork inherited from [the original project](https://github.com/makevoid/motion-graphics-music-video-skill).

The original icon was generated with Nano Banana 2 through Fal.ai (request ID `01a0df1d-5db4-7ad2-a483-749410e335e7`). This records the provenance of the existing artwork. This fork contains no provider adapter or workflow for regenerating it.
